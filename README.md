# MIGAQ 予約・顧客・売上管理システム

MIGAQ 印象改善サロン専用の予約管理システムです。

## このシステムでできること

- Googleスプレッドシートへの予約入力
- ボタン1つでGoogleカレンダーへ自動反映
- 重複予約の自動チェック
- 来店管理
- 売上の自動集計

## 使うツール（全部無料）

| ツール | 役割 |
|---|---|
| Googleスプレッドシート | 予約データの入力・管理 |
| Googleカレンダー | 予約スケジュールの表示 |
| Google Apps Script | 自動化プログラム |

## フォルダ説明

```
MIGAQ-AI/
├── gas/            Google Apps Scriptのプログラムファイル
├── docs/           操作マニュアル・設定手順
└── spreadsheet/    スプレッドシートの設計書
```
