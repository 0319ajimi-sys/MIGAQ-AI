# MIGAQ SNS自動投稿 セットアップガイド
## プログラミング初心者向け・完全手順書

---

## このガイドでできるようになること

```
毎朝8時に自動で
・Instagramに投稿
・X（Twitter）に投稿
・Hotpepperブログ用の文章をメールで受け取る

→ あなたは何もしなくてOK！
```

---

## 全体の流れ（5つのステップ）

```
STEP 1: Googleスプレッドシートを用意する（5分）
STEP 2: プログラムを貼り付ける（10分）
STEP 3: メール通知だけ動かしてみる（5分）
STEP 4: X（Twitter）の自動投稿を設定する（15分）
STEP 5: Instagramの自動投稿を設定する（30分）
```

> まずSTEP 3まで完了させてください。
> メールが届いたら成功です。その後でSTEP 4・5に進みましょう。

---

## 必要なもの（全部無料）

| 必要なもの | 用途 |
|---|---|
| Googleアカウント（Gmail） | すべての基盤 |
| X（Twitter）のアカウント | X自動投稿用 |
| Instagramのビジネスアカウント | Instagram自動投稿用 |
| Facebookのアカウント | InstagramのAPI利用に必要 |

# STEP 1：Googleスプレッドシートを用意する

## 1-1. スプレッドシートを新規作成する

1. Chromeを開く
2. [https://sheets.google.com](https://sheets.google.com) にアクセス
3. 左上の「**＋ 新しいスプレッドシート**」をクリック
4. 左上の「無題のスプレッドシート」をクリックして、名前を変える
   → **「MIGAQ管理システム」** と入力してEnter

これでスプレッドシートの準備完了です。

---

# STEP 2：プログラムを貼り付ける

## 2-1. Apps Scriptを開く

スプレッドシートのメニューから：

```
「拡張機能」→「Apps Script」をクリック
```

新しいタブで「Apps Script」の画面が開きます。

---

## 2-2. 既存のコードを全部消す

Apps Scriptの画面を開くと、最初から以下のようなコードが入っています：

```javascript
function myFunction() {

}
```

これを**全部選択して削除**してください。
（Ctrl+A で全選択 → Delete キー）

---

## 2-3. ファイルを追加する

左側のパネルに「コード.gs」というファイルが1つあります。
ここに複数のファイルを追加していきます。

### ファイルの追加方法
1. 左側の「ファイル」の横にある「**＋**」ボタンをクリック
2. 「スクリプト」を選択
3. ファイル名を入力してEnter

---

## 2-4. 各ファイルにコードを貼り付ける

以下の5つのファイルを作って、それぞれコードを貼り付けます。

### ファイル一覧

| ファイル名 | 貼り付けるコード |
|---|---|
| `main` | このリポジトリの `gas/main.gs` の内容 |
| `calendar` | このリポジトリの `gas/calendar.gs` の内容 |
| `sales` | このリポジトリの `gas/sales.gs` の内容 |
| `utils` | このリポジトリの `gas/utils.gs` の内容 |
| `sns` | このリポジトリの `gas/sns.gs` の内容 |
| `sns-post` | このリポジトリの `gas/sns-post.gs` の内容 |

### コードの貼り付け方

1. Apps Scriptで左側のファイル名をクリックして選択
2. 右側のコードエリアを全選択（Ctrl+A）
3. 貼り付けたいコードをコピー（Ctrl+C）
4. Apps Scriptのコードエリアに貼り付け（Ctrl+V）
5. 保存（Ctrl+S）

> **コードはどこにありますか？**
> このガイドと同じリポジトリの `gas/` フォルダにあります。
> GitHubでファイルを開いて「Raw」ボタンを押すと全文コピーできます。

Apps Scriptのタブを閉じて、スプレッドシートのタブに戻ります。

**ページをリロード（F5キー）** してください。

しばらく待つと、メニューバーに「**🦷 MIGAQ管理**」が表示されます。

# STEP 3：メール通知だけ動かしてみる

まずはInstagramやXは無視して、**メールが届くかだけ確認**します。

```
「🦷 MIGAQ管理」→「SNS完全自動投稿」→「① SNSカレンダーシートを作成」
```

クリックすると確認ダイアログが出るので「OK」を押します。
→ 「SNSカレンダー」というシートが自動で作られます。

## 3-2. API設定欄を追加する

```
「🦷 MIGAQ管理」→「SNS完全自動投稿」→「② API設定を追加」
```

→ 「設定」シートに入力欄が追加されます。

---

## 3-3. 設定シートを確認する

「設定」シートを開いてください。
以下のような表になっているはずです：

| 行 | A列（項目名） | B列（設定値） |
|---|---|---|
| 4 | SNS通知メール | （あなたのGmailアドレスが自動入力） |
| 5 | 自動投稿 | OFF |
| 6 | Instagram アカウントID | （空欄） |
| 7 | Instagram アクセストークン | （空欄） |
| 8 | Instagram 投稿用画像URL | （空欄） |
| 9 | X API Key | （空欄） |
| 10 | X API Secret | （空欄） |
| 11 | X Access Token | （空欄） |
| 12 | X Access Token Secret | （空欄） |

> B4のメールアドレスが自分のものか確認してください。
> 違う場合は正しいGmailアドレスに変更してください。

---

## 3-4. テストメールを送ってみる

```
「🦷 MIGAQ管理」→「SNS完全自動投稿」→「🚀 今すぐ自動投稿（テスト実行）」
```

> **「承認が必要です」と出た場合：**
> 1. 「続行」→「詳細を表示」→「MIGAQ管理システム（安全ではないページ）に移動」
> 2. 「許可」をクリック
> 3. もう一度「🚀 今すぐ自動投稿（テスト実行）」を実行

しばらく待つと、B4に入力したメールアドレスにメールが届きます。

### ✅ メールが届いたら STEP 3 完了！

メールの内容に今日の投稿文が入っていれば成功です。
Instagramは「スキップ」、Xは「X API未設定」と表示されていればOKです。

# STEP 4：X（Twitter）の自動投稿を設定する

## 4-1. X Developer Portalにアクセスする

1. [https://developer.twitter.com](https://developer.twitter.com) にアクセス
2. 右上の「Sign in」からXのアカウントでログイン

---

## 4-2. アプリを作成する

1. 「**Developer Portal**」に入る
2. 左メニューの「**Projects & Apps**」→「**New App**」をクリック
3. アプリ名を入力（例：`MIGAQ-SNS-Bot`）
4. 「**Next**」→ 表示されるキーをコピーして**必ず保存**する

> ⚠️ この画面は一度しか表示されません！必ずメモ帳などに保存してください。

コピーするもの（この時点では3つ）：
- **API Key** → メモ帳に貼り付け
- **API Key Secret** → メモ帳に貼り付け
- **Bearer Token** → メモ帳に貼り付け（今回は使わない）

---

## 4-3. アクセストークンを発行する

1. 作成したアプリのページで「**Keys and tokens**」タブをクリック
2. 「**Authentication Tokens**」の「**Access Token and Secret**」の横の「**Generate**」をクリック
3. 表示された2つをコピーして保存：
   - **Access Token** → メモ帳に貼り付け
   - **Access Token Secret** → メモ帳に貼り付け

---

## 4-4. アプリの権限を「読み書き」に変更する

> ⚠️ この設定をしないとツイートできません

1. アプリの「**Settings**」タブをクリック
2. 「**User authentication settings**」の「**Edit**」をクリック
3. 「**App permissions**」を「**Read and write**」に変更
4. 「**Save**」をクリック

---

## 4-5. スプレッドシートの設定シートにキーを入力する

「設定」シートを開いて、以下のように入力します：

| 行 | A列 | B列に入力する値 |
|---|---|---|
| 9 | X API Key (Consumer Key) | メモしたAPI Key |
| 10 | X API Secret | メモしたAPI Key Secret |
| 11 | X Access Token | メモしたAccess Token |
| 12 | X Access Token Secret | メモしたAccess Token Secret |

---

## 4-6. Xへのテスト投稿をしてみる

```
「🦷 MIGAQ管理」→「SNS完全自動投稿」→「🐦 Xにテスト投稿」
```

「✅ Xへのテスト投稿が成功しました！」と表示されればOK！

Xのアカウントを開いて、テスト投稿が表示されているか確認してください。

### ✅ 投稿されていたら STEP 4 完了！

# STEP 5：Instagramの自動投稿を設定する

> Instagramは設定が少し複雑です。
> 時間があるときに落ち着いて進めてください（30〜60分）

## 5-1. Instagramをビジネスアカウントに切り替える

（すでにビジネスアカウントの場合はスキップ）

Instagramアプリで：
1. プロフィール → 右上の「≡」→「設定」
2. 「アカウント」→「プロフェッショナルアカウントに切り替える」
3. 「ビジネス」を選択して進む

---

## 5-2. FacebookページをInstagramと連携させる

1. Facebook（[https://www.facebook.com](https://www.facebook.com)）にログイン
2. 左メニューの「**ページ**」→「**新しいページを作成**」
3. ページ名：「MIGAQ印象改善サロン」など
4. Facebookページの「**設定**」→「**Instagramとリンク**」→連携する

---

## 5-3. Meta for Developersでアプリを作る

1. [https://developers.facebook.com](https://developers.facebook.com) にアクセス
2. 右上「**マイアプリ**」→「**アプリを作成**」
3. 「**その他**」→「**次へ**」
4. アプリ名：「MIGAQ SNS Bot」などを入力→「**アプリを作成**」

---

## 5-4. Instagram Graph APIを追加する

1. アプリのダッシュボードで「**製品を追加**」
2. 「**Instagram Graph API**」の「**設定**」をクリック
3. 左メニューの「**Instagram Basic Display**」→「**設定に進む**」

---

## 5-5. Instagram ユーザーIDを取得する

1. アプリダッシュボードの「**ツール**」→「**グラフAPIエクスプローラー**」を開く
2. 右上のドロップダウンで作ったアプリを選択
3. 「**ユーザーまたはページ**」→「**Instagramビジネスアカウントを取得**」を選択
4. 表示された数字（例：`17841400000000000`）をメモ → **これがInstagramアカウントID**

---

## 5-6. アクセストークンを取得する（長期トークン）

1. グラフAPIエクスプローラーで「**アクセストークンを生成**」をクリック
2. 権限に「`instagram_basic`」「`instagram_content_publish`」「`pages_read_engagement`」を追加
3. 「**アクセストークンを生成**」→ Facebook/Instagramのログイン承認をする
4. 表示されたトークンをコピー → **これは短期トークン（60日で切れる）**

---

## 5-7. 長期トークンに変換する

短期トークンは2時間で切れるため、60日間有効なトークンに変換します。

Apps Scriptで以下の関数を実行します：

**Apps Scriptを開いて、一番下にこのコードを一時的に追加：**

```javascript
function getLongLivedToken() {
  var shortToken = '（ここに短期トークンを貼り付ける）';
  var appId = '（Meta for DevelopersのアプリIDを貼り付ける）';
  var appSecret = '（アプリシークレットを貼り付ける）';

  var url = 'https://graph.facebook.com/v19.0/oauth/access_token' +
    '?grant_type=fb_exchange_token' +
    '&client_id=' + appId +
    '&client_secret=' + appSecret +
    '&fb_exchange_token=' + shortToken;

  var response = UrlFetchApp.fetch(url);
  var result = JSON.parse(response.getContentText());
  Logger.log('長期トークン: ' + result.access_token);
}
```

実行後、「**ログ**」（表示→ログ）を開いて表示されたトークンをコピーします。

> **アプリIDとアプリシークレットはどこ？**
> Meta for Developers → アプリのダッシュボード → 「設定」→「ベーシック」に記載されています。

---

## 5-8. 投稿用の画像をアップロードする

Instagramの投稿には**必ず画像が必要**です。

1. MIGAQのロゴ画像や雰囲気に合った写真を用意する
2. 以下のいずれかのサービスに画像をアップロードする：
   - **Cloudinary**（[https://cloudinary.com](https://cloudinary.com)）無料で利用可能
   - **Imgur**（[https://imgur.com](https://imgur.com)）無料
   - **Google Drive**で「リンクを知っている全員が閲覧可能」に設定してURLをコピー
3. 画像のURLをコピーしておく（例：`https://res.cloudinary.com/xxx/image/upload/xxx.jpg`）

> **Google Driveの場合の注意**
> Google DriveのURLはそのままでは使えません。
> `https://drive.google.com/uc?export=view&id=ファイルID` の形式に変換が必要です。

---

# よくあるエラーと対処法

## ❌「承認が必要です」が出る
→ GASのメニューで「許可」を押してください。初回だけ必要です。

## ❌「X投稿エラー：401」が出る
→ APIキーの入力ミスか、アプリの権限が「Read only」になっています。
→ STEP 4-4 の手順でアプリ権限を「Read and write」に変更してください。

## ❌「Instagram メディア作成失敗」が出る
→ 画像URLが公開されていない可能性があります。
→ ブラウザのシークレットウィンドウで画像URLを開いて見えるか確認してください。

## ❌「SNSカレンダー」シートが見つからない
→ STEP 3-1 の「SNSカレンダーシートを作成」をもう一度実行してください。

## ❌ メールが届かない
→ 設定シートのB4のメールアドレスを確認してください。
→ 迷惑メールフォルダも確認してください。

# Instagramのトークン更新（60日ごと）

アクセストークンは60日で期限切れになります。
期限が近づいたらメールが届くように設定するか、月1回手動で更新してください。

STEP 5-6 〜 5-7 の手順を繰り返して新しいトークンを設定シートのB7に貼り付けてください。

# わからないことがあったら

Apps Scriptのエラーメッセージをそのままコピーして
AIアシスタント（Claude、ChatGPTなど）に聞くと解決策を教えてくれます。

例：
```
「Google Apps Scriptでこんなエラーが出ました：
（エラーメッセージをそのままペースト）
MIGAQのSNS自動投稿の設定をしているのですが、
どう対処すればいいですか？」
```
