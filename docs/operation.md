# 日常の使い方

## 毎日の流れ

```
1. スプレッドシートを開く
2. 「予約一覧」シートに予約を入力
3. 「カレンダーに登録」ボタンを押す
4. 来店したら「来店状況」を「来店済み」に変更
5. 売上集計シートで本日の売上を確認
```

---

## 予約の入力方法

1. Googleスプレッドシートを開く
2. 「予約一覧」シートをクリック
3. 新しい行に以下を入力する：

| 項目 | 入力方法 |
|---|---|
| 予約日 | 日付を入力（例：2026/05/20） |
| 開始時間 | 時間を入力（例：10:00） |
| 終了時間 | 時間を入力（例：11:30） |
| 顧客名 | お客様の名前を入力 |
| 電話番号 | 電話番号を入力 |
| メニュー | リストから選ぶ |
| 担当者 | リストから選ぶ |
| 金額 | 金額を数字で入力（例：15000） |
| 来店状況 | 「予約済み」を選ぶ |
| 支払い方法 | リストから選ぶ |

※ 予約ID・カレンダー登録は自動で入力されます

---

## カレンダーに登録する方法

1. 予約を入力し終わったら
2. 「カレンダーに登録」ボタンを押す（スプレッドシート上部に表示）
3. 「登録しました」と表示されたら完了
4. L列の「カレンダー登録」が「済」になっていることを確認

---

## 来店確認の方法

お客様が来店したら：

1. 「予約一覧」シートで該当のお客様を探す
2. J列「来店状況」を「来店済み」に変更
3. K列「支払い方法」を確認・入力

キャンセルの場合：
- J列「来店状況」を「キャンセル」または「無断キャンセル」に変更

---

## 売上確認の方法

1. 「売上集計」シートをクリック
2. 本日の売上・月の売上が表示されています

---

## よくあるトラブル

### カレンダーに登録されない
- カレンダーIDが正しく設定されているか確認（「設定」シートのB1）
- 時間の入力形式が正しいか確認（例：10:00）

### エラーが出る
- エラーメッセージをそのままメモして担当者に連絡

### 重複の警告が出る
- 同じ時間帯にすでに予約が入っています
- 時間を変更してから再度登録してください
