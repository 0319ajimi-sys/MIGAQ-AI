# Lovable 完全版プロンプト — 美容室電子同意書アプリ

以下を Lovable のチャット欄にそのままコピー&ペーストしてください。

---

## ▼ ここから ▼

美容室向けの電子同意書 Web アプリを作成してください。
スマホ専用のシングルページアプリです。

---

## 【目的】
施術後の返金トラブルを防ぐため、施術前にお客様の同意と電子署名を取得するアプリ。
美容師が3分以内に入力でき、署名済みPDFをその場でダウンロードできる。

---

## 【デザインシステム】

### カラー
- 背景: #FFFFFF（白）
- メインテキスト: #0A0A0A（ほぼ黒）
- プレースホルダー・ラベル: #A0A0A0 〜 #D0D0D0
- ボーダー: #D8D8D8（入力欄）、#EBEBEB（セクション区切り）
- アクセント黒: #0A0A0A（ボタン・チェックボックスON・ヘッダー）
- 低リスク文字: #555555
- 中リスク文字: #6B3A00
- 高リスク文字: #7B0000
- 無効ボタン: #D8D8D8

### フォント
- 見出し（「施術同意書」など）: セリフ体（font-serif）
- 本文・ラベル: サンセリフ（デフォルト）
- セクションラベル: 極小（9px）、letter-spacing 4px、大文字、グレー (#B0B0B0)

### 入力欄スタイル
- ボーダーはボトムのみ（border-b）
- フォーカス時: border-color が #0A0A0A に変化
- パディング: py-3、フォントサイズ 15px

### ボタンスタイル
- 送信ボタン: 全幅・黒背景・白テキスト・py-4・letter-spacing 5px
- 無効時: 背景 #D8D8D8・テキスト #F0F0F0・カーソル not-allowed

### チェックボックス（カスタム）
- サイズ: 18×18px の正方形
- チェックOFF: border #C8C8C8・背景 white
- チェックON: 背景 #0A0A0A・白チェックマーク（SVG）
- 行全体がタップ領域（最低44px高さ）

### セクションラベルのデザイン
各セクションの先頭に以下の形式で表示:
```
[極小文字 "01 — お客様情報"] ─────────────────────
```
左がテキスト、右に flex-1 の水平線（bg #EBEBEB・height 1px）

以下4項目のカスタムチェックボックスリスト（border-t から開始、各行 border-b）:

| 縮毛矯正履歴あり | 酸性ストレート含む |
| セルフカラー履歴あり | 市販染料・白髪染め含む |

### セクション05 — リスク説明（自動生成・リアルタイム更新）

## 【リスク自動生成ロジック】

### スコア計算

```typescript
let score = 0;

// 希望カラーに以下が含まれる場合 wantsBleach = true
// "ブリーチ" "明るい" "ハイトーン" "金" "白"

if (黒染めチェック) {
  score += 3;
  if (wantsBleach) score += 2;  // 追加
}
if (ブリーチチェック) score += 2;
if (縮毛矯正チェック) score += 2;
if (セルフカラーチェック) score += 1;
if (黒染め && ブリーチ 両方) score += 2;  // 複合リスク追加

// レベル判定
if (score === 0)      level = 'none'
else if (score <= 2)  level = 'low'
else if (score <= 5)  level = 'medium'
else                  level = 'high'
```

### 表示するリスク文言（条件付き）

**黒染めチェック時に表示:**
> 黒染め履歴があります。明るいカラー・ブリーチ施術では色が均一に入らず、オレンジや緑がかった色が残る可能性があります。

**黒染め＋wantsBleach の場合に追加:**
> 希望カラーに対して黒染め履歴のリスクが高い状態です。1回の施術で到達できない場合があり、複数回の施術が必要になることがあります。

**ブリーチチェック時に表示:**
> ブリーチ履歴があります。毛髪がダメージを受けており、断毛・切れ毛・チリつきのリスクがあります。

**縮毛矯正チェック時に表示:**
> 縮毛矯正の履歴があります。薬剤の化学的相互作用により、パーマ・カラーの仕上がりが予想と異なる場合があります。

**セルフカラーチェック時に表示:**
> セルフカラーの履歴があります。使用した染料の残留により、サロンカラーの発色が不均一になる場合があります。

**黒染め＋ブリーチ 両方チェック時に追加:**
> 【複合リスク】黒染め × ブリーチの組み合わせは、1回の施術で希望色に到達できない可能性が高いです。

**常時表示（共通事項・2件）:**
> アレルギー・かぶれ（かゆみ・赤み・腫れ）が現れた場合は直ちにお申し出ください。

> 施術後のホームケアが仕上がりの維持に大きく影響します。担当スタイリストの指示に従ってください。

## 【PDF生成仕様】

### タイミング
「同意して送信」ボタン押下後、以下を順番に実行:
1. html2canvas と jsPDF を動的インポート（import()）
2. 非表示 div（position:fixed left:-9999px）に PDF用HTMLを生成
3. html2canvas でキャプチャ（scale:2, useCORS:true, backgroundColor:'#ffffff'）
4. jsPDF で A4縦サイズ PDF に変換
5. PDF をダウンロード（ファイル名: `同意書_[氏名]_[日付].pdf`）
6. div を DOM から削除
7. 完了画面を表示

### PDF の内容（上から順に）

```
MIGAQ IMPRESSION SALON（極小・グレー）
施術同意書（大文字・太字）         [日付]（右寄せ）
─────────────────────────────────────────

┌──────────────┬──────────────┐
│ お客様情報      │ （空欄）       │
│ 氏名: 山田花子様 │              │
│ 電話: 090-...  │              │
└──────────────┴──────────────┘

希望カラー: ミルクティーベージュ（希望カラーがある場合のみ）

施術履歴（2×2グリッド）:
■ 黒染め    □ ブリーチ
□ 縮毛矯正  □ セルフカラー
（チェックありは黒背景・ボーダー、なしはグレー）

リスク説明（左に縦線・色付き）:
[リスクバッジ]
— リスクテキスト...

同意:
☑ 上記リスク説明の内容を理解しました...

電子署名:
[署名画像]
署名日時: 2025年6月2日 14:30

─────────────────────────────────────────
本書面は電子的に作成されました。MIGAQ Impression Salon
```

### PDF用HTML のフォント
```

```
（外部フォント不使用、システムフォントのみ）

## 【技術仕様】

- **フレームワーク:** React + TypeScript + Vite
- **スタイリング:** Tailwind CSS
- **PDF生成:** jspdf + html2canvas（npm install jspdf html2canvas）
- **電子署名:** HTML Canvas（ライブラリなし）
  - MouseEvent と TouchEvent 両対応
  - ResizeObserver でサイズ自動調整
  - devicePixelRatio 対応（Retina/高解像度スクリーン）
- **状態管理:** React useState のみ（外部ライブラリ不要）
- **バックエンド:** なし（ローカルのみ・Supabase は後から追加予定）
- **ルーティング:** なし（シングルページ・done ステートで切り替え）
- **最大幅:** スマホサイズに最適化（max-w-md mx-auto または full-width）
