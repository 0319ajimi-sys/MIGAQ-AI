# スプレッドシート設計書

## シート構成

Googleスプレッドシートに以下の4枚のシートを作ります。

---

## シート1：「予約一覧」

予約を入力するメインのシートです。

| 列 | 列名 | 内容 | 入力例 |
|---|---|---|---|
| A | 予約ID | 自動で番号が入る | R001 |
| B | 予約日 | 来店する日付 | 2026/05/20 |
| C | 開始時間 | 施術開始の時間 | 10:00 |
| D | 終了時間 | 施術終了の時間 | 11:30 |
| E | 顧客名 | お客様のお名前 | 山田 花子 |
| F | 電話番号 | お客様の電話番号 | 090-1234-5678 |
| G | メニュー | 施術内容 | ホワイトニング |
| H | 担当者 | 担当スタッフ名 | MIGAQ太郎 |
| I | 金額 | 料金（税込） | 15000 |
| J | 来店状況 | 来店したかどうか | 予約済み / 来店済み / キャンセル |
| K | 支払い方法 | 支払い方法 | 現金 / カード / PayPay |
| L | カレンダー登録 | 自動入力される | 済 / 未 |
| M | メモ | 特記事項など | アレルギーあり |

---

## シート2：「売上集計」

自動で計算される売上のまとめシートです。

| 項目 | 内容 |
|---|---|
| 日別売上 | その日の合計金額 |
| 月別売上 | その月の合計金額 |
| メニュー別売上 | メニューごとの金額 |
| 担当者別売上 | 担当ごとの金額 |
| 来店数 | 月の来店人数 |

---

## シート3：「マスタ」

ドロップダウンリストで使う選択肢の一覧です。

| 項目 | 選択肢 |
|---|---|
| メニュー | ホワイトニング / HBL / セットメニュー / オプション |
| 来店状況 | 予約済み / 来店済み / キャンセル / 無断キャンセル |
| 支払い方法 | 現金 / クレジットカード / PayPay / LINE Pay / その他 |
| 担当者 | （オーナーが追加する） |

---

## シート4：「設定」

システムで使う設定値を入れるシートです。

| 項目 | 内容 |
|---|---|
| カレンダーID | GoogleカレンダーのID（後で設定） |
| 営業開始時間 | 10:00 |
| 営業終了時間 | 20:00 |
