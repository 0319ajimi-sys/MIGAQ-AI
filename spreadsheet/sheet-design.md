# スプレッドシート設計書

## シート構成

Googleスプレッドシートに以下の4枚のシートを作ります。

---

## シート1：「予約一覧」

予約を入力するメインのシートです。

| 列 | 列名 | 内容 | 入力例 |
|---|---|---|---|
| A | 予約ID | 自動で番号が入る | R001 |
| B | 予約日 | 来店する日付 | 2026/05/20 |
| C | 開始時間 | 施術開始の時間 | 10:00 |
| D | 終了時間 | 施術終了の時間 | 11:30 |
| E | 顧客名 | お客様のお名前 | 山田 花子 |
| F | 電話番号 | お客様の電話番号 | 090-1234-5678 |
| G | メニュー | 施術内容 | ホワイトニング |
| H | 担当者 | 担当スタッフ名 | MIGAQ太郎 |
| I | 金額 | 料金（税込） | 15000 |
| J | 来店状況 | 来店したかどうか | 予約済み / 来店済み / キャンセル |
| K | 支払い方法 | 支払い方法 | 現金 / カード / PayPay |
| L | カレンダー登録 | 自動入力される | 済 / 未 |
| M | メモ | 特記事項など | アレルギーあり |

---

## シート2：「売上集計」

自動で計算される売上のまとめシートです。

| 項目 | 内容 |
|---|---|
| 日別売上 | その日の合計金額 |
| 月別売上 | その月の合計金額 |
| メニュー別売上 | メニューごとの金額 |
| 担当者別売上 | 担当ごとの金額 |
| 来店数 | 月の来店人数 |

---

## シート3：「マスタ」

ドロップダウンリストで使う選択肢の一覧です。

| 項目 | 選択肢 |
|---|---|
| メニュー | ホワイトニング / HBL / セットメニュー / オプション |
| 来店状況 | 予約済み / 来店済み / キャンセル / 無断キャンセル |
| 支払い方法 | 現金 / クレジットカード / PayPay / LINE Pay / その他 |
| 担当者 | （オーナーが追加する） |

---

## シート4：「設定」

システムで使う設定値を入れるシートです。

| 項目 | 内容 |
|---|---|
| カレンダーID | GoogleカレンダーのID（後で設定） |
| 営業開始時間 | 10:00 |
| 営業終了時間 | 20:00 |
| SNS通知メール | 投稿案の送信先メールアドレス（自動入力） |

---

## シート5：「SNSカレンダー」（SNS秘書AIが自動作成）

毎朝8時に自動生成された投稿案を管理するシートです。

| 列 | 列名 | 内容 | 例 |
|---|---|---|---|
| A | 日付 | 投稿予定日 | 2026/05/25 |
| B | 曜日 | 月〜日 | 月 |
| C | テーマ | 今日のテーマ | 清潔感・第一印象 |
| D | プラットフォーム | 投稿先SNS | Instagram / X / Hotpepper |
| E | タイトル | 投稿タイトル | 清潔感って、努力次第で必ず上がる。 |
| F | 本文 | 投稿本文（コピペ用） | 〜（全文）〜 |
| G | ハッシュタグ | ハッシュタグ一覧 | #清潔感 #印象改善 ... |
| H | ターゲット | 想定読者 | 清潔感に悩む20〜30代男女 |
| I | 目的 | 投稿の目的 | 保存率UP・フォロワー獲得 |
| J | 状態 | 投稿したかどうか | 未投稿 / 投稿済み / スキップ |
| K | 投稿日時 | 実際に投稿した日時 | 2026/05/25 12:00 |
| L | メモ | 備考・改善メモ | 保存数が多かった等 |

### SNS自動化の仕組み

```
毎朝8:00（自動）
  ↓
今日の曜日・週を判定
  ↓
テーマを自動決定（4週ローテーション）
  ↓
Instagram・X・Hotpepperの投稿文を生成
  ↓
メールで送信（HTMLメール・コピペOK）
  ↓
SNSカレンダーシートに記録
  ↓
投稿後にシートの「状態」を「投稿済み」に変更
```

### セットアップ手順（初回のみ）

1. スプレッドシートを開いてメニューが表示されるのを待つ
2. 「🦷 MIGAQ管理」→「📱 SNS管理」→「SNSカレンダーシートを作成」を実行
3. 「SNS管理」→「毎朝SNS投稿案をメール送信（トリガー設定）」を実行
4. 「SNS管理」→「今日の投稿案をすぐに送信（テスト）」でメールが届けば完了
