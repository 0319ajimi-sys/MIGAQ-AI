# MIGAQ SNS戦略マスタードキュメント

## ブランド定義

**MIGAQ = 印象改善サロン**
「単なる美容サロン」ではなく、
**第一印象・清潔感・垢抜け・自信・爽やかさ・信頼感** を提供するブランド。

場所：京都四条大宮
主軸：ホワイトニング × HBL（眉毛）

- 第一印象は人生に影響する
- 清潔感は年収・出世・恋愛に直結する
- 歯・眉・髪で印象は大きく変わる
- 自然な垢抜けが一番強い
- "ちゃんとしてる感"が信頼を生む

## 各プラットフォーム戦略

### Instagram
- **トーン**：少し丁寧・共感重視・世界観重視
- **目的**：保存・フォロー・来店予約
- **頻度**：フィード週3〜4本 / リール週2本
- **コンテンツ比率**：
  - 教育系（清潔感・垢抜けTips）：40%
  - 実績・ビフォーアフター：25%
  - サロン紹介・メニュー：20%
  - 口コミ・お客様の声：15%

### X（旧Twitter）
- **トーン**：短く刺さる・思想強め・共感
- **目的**：拡散・認知・フォロワー獲得
- **頻度**：毎日1〜3ツイート
- **コンテンツ比率**：
  - 思想系（清潔感・印象論）：50%
  - Tips系（歯・眉ケア）：30%
  - サロン告知：20%

### ホットペッパービューティーブログ
- **トーン**：予約に繋がる・写真説明充実
- **目的**：検索流入・予約転換
- **頻度**：週1〜2本
- **コンテンツ比率**：
  - メニュー詳細・施術レポ：40%
  - お客様事例：30%
  - 季節・イベント訴求：30%

## クロージング設計（教育型）

押し売りではなく **「継続する意味を教える」** スタイルで行う。

### 自然な誘導フロー
```
施術後の会話
→「ホワイトニングは継続が大事で、週1回×3ヶ月が一番結果出ます」
→「サブスクだと毎回の費用も抑えられますし、習慣になりやすいですよ」
→「次回◯日頃どうですか？」
```

### 口コミ依頼タイミング
- 施術終了直後の満足度が高い瞬間
- 「よかったらGoogleかホットペッパーに書いていただけると嬉しいです」
- 「お友達への紹介もしていただけると、次回◯◯のサービスをお渡しできます」
