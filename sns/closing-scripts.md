# クロージング・口コミ誘導スクリプト集

## 基本方針
「押し売りではなく、継続する意味を教育する」
お客様が自分で「やりたい」と思うように設計する。

---

## 施術後のクロージングフロー

### ホワイトニング施術後

**ステップ1：満足感の確認**
```
「今日、いかがでしたか？
 白さの変化、感じていただけましたか？」
```

**ステップ2：継続の意味を教育する**
```
「ホワイトニングって、実は継続することで
 どんどん定着していくんですよ。

 1回でも変化は出るんですが、
 週1回を2〜3ヶ月続けると
 "この白さが当たり前"になっていきます。

 逆に間があいてしまうと、
 少しずつ戻っていってしまうので、
 習慣にしていただくのが一番なんです。」
```

**ステップ3：サブスクの自然な提案**
```
「もし継続しようと思っていただけるなら、
 月額プランを使っていただくと、
 1回あたりの費用もお得になりますし、
 来るタイミングも決まるので習慣にしやすいですよ。

 どうされますか？」
```

**ステップ4：次回予約**
```
「次回、◯週間後くらいにまた来ていただくのが
 ちょうどいいタイミングなんですが、
 今日のうちにご予約しておきますか？」
```

## 口コミ依頼スクリプト

### タイミング：施術直後、満足いただけた瞬間

**基本パターン**
```
「今日ありがとうございました。

 もし今日来てよかったと思っていただけたなら、
 GoogleかホットペッパーにひとことでもOKなので、
 口コミを書いていただけると嬉しいです。

 口コミを見て来てくださる方が多くて、
 書いていただいた口コミが
 次のお客様の背中を押してくれるんです。」
```

**より自然なパターン（柔らかい言い方）**
```
「よかったらで全然いいんですが、
 Googleに感想を書いていただけると
 すごく励みになります。

 検索で来てくださる方に見ていただける場所なので、
 ◯◯さんの一言が他の誰かを助けることになります。」
```

**施術後にLINE・メッセージで送るパターン**
```
本日はご来店ありがとうございました！
変化を感じていただけていたら嬉しいです。

もしよかったら、
Googleまたはホットペッパーへのクチコミをいただけますと
大変励みになります。

また次回もお待ちしております。
MIGAQ スタッフ一同
```

## 保存率が上がる投稿のコツ

### 保存される投稿の特徴
1. **後で見返したくなる情報がある**（Tips系・まとめ系）
2. **「これ友達に教えたい」と思う内容**（驚き・共感・有益）
3. **段階的に読み進めたくなる構成**（①②③形式）
4. **「自分のこと言われてる」と感じる共感軸**

### 投稿末尾に入れるフレーズ（保存誘導）
```
「後で見返せるように保存しておくのがおすすめです」
「スクリーンショットして活用してください」
「これ、気になる人に送ってあげてください」
```

### 投稿の書き出しで保存率が上がるパターン
```
「知っておくと得する話です」
「○○してる人に読んでほしい」
「これは保存推奨です」
「正直に言います」
「意外と知られていないこと」
```
